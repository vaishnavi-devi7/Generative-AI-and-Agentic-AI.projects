# GenAI & Agentic AI — 2 Days of Building

A hands on journey into **Generative AI, Agentic AI, RAG, and AI-powered workflows**.

Two days of learning, experimenting, breaking things, fixing them, and actually getting things to work. ⚡

## Day 1 — Understanding AI Agents

Day 1 was all about understanding the bigger AI ecosystem and how intelligent agents communicate, make decisions, and interact with humans.

### Topics explored

- AI Agent Ecosystems & Frameworks
- A2H (Agent-to-Human) Protocol
- Human-Agent Communication
- Agent Decision Layers
- Unified Messaging
- AI Tokenization
- Execution Tools
- AWS Deployment

The main takeaway: **understanding what happens behind the scenes when AI systems start working together.**

## Day 2 — RAG + Building Projects

Day 2 moved from concepts to actual implementation.

### 📄 Document Q&A with RAG

Built a **Document Q&A RAG system** that allows users to upload a PDF and ask questions about its content.

### Flow

`PDF → Text Extraction → Chunking → Embeddings → ChromaDB → Retrieval → LLM → Answer`

### 🤖 AI Job & Portfolio Matching

Also built an AI workflow that connects job requirements with relevant portfolio projects using semantic search and generates a personalized cold email.

### Flow

`Job → Skills → Semantic Search → Portfolio → LLM → Email`

##  Tech Stack
